## 🍉 Retro Ninja - Web Canvas Game

A browser-based arcade game inspired by Fruit Ninja, built entirely with vanilla JavaScript, HTML5 Canvas, and CSS3. Slice the fruits, avoid the bombs, and get the highest score before the timer runs out!

**Main Features**
* **HTML5 Canvas Rendering**: Custom physics, gravity, and slicing mechanics for fruits and bombs.
* **Combo System**: Earn score multipliers for quick, consecutive slices.
* **Local Storage**: Automatically saves and retrieves the player's high score across browser sessions.
* **Retro Aesthetic**: Features custom pixel-art sprites, a retro font, and immersive sound effects.

**How to Play**
1. Clone or download the repository to your local machine.
2. Ensure the asset folders (`ressourcesimages/` and `ressourceson/`) are in the same directory as the main files.
3. Open `index.html` in any modern web browser.
4. Click **JOUER** to start.
5. **Click and drag** your mouse across the screen to slice the fruits. Avoid the black bombs!

**File Architecture**
* `index.html`: The main entry point containing the game UI and Canvas element.
* `style.css`: Styling for the menus, score displays, and custom font integration.
* `script.js`: The core game engine containing the animation loop, collision detection, and logic.
* `retro.ttf`: The custom retro font used for the user interface.
